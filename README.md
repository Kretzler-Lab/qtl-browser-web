# qtl-browser-web

This project holds the code for the QTL browser. This project was templated with `npx create vite@latest ./qtl-browser-web --template react-ts`

## Development 

First install [Node.js](https://nodejs.org/download/release/v20.19.0/) v20.19.0 via [NVM](https://github.com/nvm-sh/nvm)

1. Install packages:
```
npm i
```
2. Build the .css and .css.map files:
```
npm run build-css
```
3. Start the server:
```
npm start
```
